# VehDiag_gnl — 售后诊断助手（通用版）

网址：https://gcy2016.github.io/VehDiag_gnl/ （不需要密码）

不绑定任何车型资料：**DBC 和诊断问卷由使用者自己加载**，所有文件只在本机浏览器内读取，不会上传。

## 使用
1. **加载资料**（都可以不加载，加载后记在本机浏览器里，下次打开不用重新选择）
   - DBC：选一个或多个 `.dbc`（多个会合并），用于解析信号、画曲线
   - 诊断问卷：选 Excel（`.xlsx`），每个 Sheet 一个车型 / 配置，有多个 Sheet 时选择对应的一个；格式见 `诊断问卷模板.xlsx`
2. **选择功能**
   - 🔍 故障码查询：输入显示码或高中低字节，查故障描述、可能原因、维修建议
   - 📈 数据分析：打开 `.blf` / `.asc` 报文
     - 故障码识别：诊断仪读码应答（UDS 19 服务，含多帧）和 DBC 里广播的 DTC 信号，按问卷给出含义；列出清码等诊断过程
     - 疑似异常的状态信号（需要 DBC）
     - 信号曲线（需要 DBC）：每个信号一条泳道、各自 Y 轴；滚轮 / 双指缩放、拖动平移、双击复位、悬停取值
     - 报文提取：按 ID / 范围 / 报文名筛选，“仅诊断报文”一键筛选；点一行看解析（DBC 信号值、诊断报文的帧类型与 UDS 解释，如 7F 否定码含义）

## 诊断问卷格式
表头行需包含这几列（列名保持英文，网页按列名识别）：
`DTC Number`（显示码，如 U010087），其右边两列依次为高中字节、低字节；
`Faults Types`（故障描述）、`Possible Fault`（可能原因）、`Corrective`（维修建议），每项占两列：中文、英文。

## 文件
`index.html` 页面；`canlog.js` 报文读取、信号解码、故障码识别；`plot.js` 曲线；`dbc.js` DBC 解析；`qn.js` 问卷解析；
`uds.js` 通用诊断知识表；`lib/xlsx.full.min.js` Excel 读取组件（SheetJS，Apache-2.0，见 `lib/xlsx.LICENSE`）。
